# 任务清单与附件预览

- `todo.updated`（兼容 `todo.update`）是当前会话的完整任务清单快照。按 ID 替换列表，空数组清空；在聊天列表上方显示一块可折叠进度，不追加普通消息。四种状态为待开始、进行中、已完成和已取消。
- 切换会话即释放清单；历史首次请求返回的新快照负责恢复。子代理私有任务清单不会覆盖主会话清单，未加载会话的事件仍由会话路由丢弃。
- 图片附件进入列表组件时自动异步下载和解码；同时最多两个预览任务。缩略图长边最大 960 像素，点击后全屏长边最大 2560 像素，支持双指缩放、拖动和双击放大／还原。GIF 等动图当前仅按解码出的默认帧显示。图片外右下角为保存和转发，操作使用原始附件文件。
- HTML 附件保留打开、保存、转发，并增加渲染按钮。点击后进入全屏 ArkWeb 浮窗，左上角和系统返回键关闭浮窗。HTML 以 UTF-8 读取，支持 JavaScript，不注入原生桥接接口，不开放本地文件访问；使用无痕 WebView，不启用 DOM Storage 或 HTTP 缓存。
- HTML 采用独立预览源。适合自包含 HTML、内嵌 CSS/JS/图片，以及手机能访问的绝对 HTTP/HTTPS 资源地址。电脑文件相对路径、同目录资源、需要登录态或本地存储的网站应用不保证可用；这不是电脑目录的镜像浏览器。
- 自动图片预览上限 32 MiB，HTML 渲染上限 4 MiB。大文件仍可使用保存／转发／系统打开；通用附件下载上限保持 128 MiB。图像格式支持取决于设备解码器，失败时显示重试入口。
- 预览下载使用独立临时文件，读取／解码完成立即删除，组件离开时释放 PixelMap；异常退出后的临时文件沿用下次启动清理。不保存会话或预览缓存。用户主动保存的文件及用户要求的通信日志保留。
- 每次预览带会话归属和生命周期代次检查，切换会话／关闭浮窗后的迟到结果不会渲染进当前界面。下载、解码和 HTML 页面完成／错误事件进入通信日志。

验证范围：仅源码检查和 ArkTS 构建；未执行自动测试、真机交互或截图检查。
